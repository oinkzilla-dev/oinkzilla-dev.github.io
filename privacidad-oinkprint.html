Política de privacidad de OinkPrint

Actualizada: 27 de noviembre de 2026.
Aplicación: OinkPrint · Android.
Desarrollador: OINKZILLA STUDIOS.
Paquete: com.oinkzilla.studios.oinkprint.
Contacto: oinkzillasupport@gmail.com.

Alcance de esta política

Describe OinkPrint 1.1.0, versión release preparada para lanzamiento con la publicidad desactivada. Esta versión no incluye Google Mobile Ads ni Google User Messaging Platform (UMP). La variante debug de desarrollo utiliza anuncios oficiales de prueba y no es la versión que se distribuirá al público.

1. Qué hace OinkPrint

OinkPrint permite preparar imágenes con medidas físicas, recortarlas, girarlas, distribuirlas en páginas y generar documentos PDF para guardar, compartir o imprimir. Sus herramientas son gratuitas. No requiere crear una cuenta en OinkPrint.

2. Fotografías, documentos y acceso a archivos

Accedemos a las imágenes que eliges mediante el selector de fotos de Android o que compartes expresamente con OinkPrint desde otra aplicación. La versión revisada no solicita acceso general a tu galería, cámara, contactos ni ubicación del dispositivo.

La app crea copias de las imágenes elegidas en su almacenamiento interno privado, para que el proyecto no dependa de permisos temporales sobre el archivo de origen. No modifica ni elimina tus fotografías originales externas. Los archivos pueden conservar metadatos de origen, como EXIF; no debe asumirse que exportar elimina todos esos metadatos.

La edición se realiza en el dispositivo. Los recortes y la corrección de perspectiva se conservan como parámetros de edición sobre la copia original. Las miniaturas y las imágenes decodificadas ayudan a reducir el consumo de memoria.

3. Proyectos guardados localmente

Los proyectos se guardan en una base de datos Room privada. Se conservan el nombre, identificadores internos, fechas de creación y modificación, páginas y orden, papel, orientación, márgenes, medidas, posiciones, giros, contornos, recortes, perspectiva y referencias a las copias de imágenes. También se guarda el proyecto reciente, la página activa, selección y guías para continuar la edición.

El guardado automático utiliza transacciones. La indicación «Guardado» aparece cuando se ha confirmado el estado correspondiente en el almacenamiento. Los cambios que aún están pendientes pueden perderse si el proceso se cierra antes de completarse la escritura. No ofrecemos recuperación de datos físicamente dañados o borrados del almacenamiento privado.

4. PDF, compartir e imprimir

Exportar crea un PDF temporal dentro de la app; no elimina el proyecto editable. Guardar PDF permite elegir una ubicación o proveedor de documentos. Compartir, abrir o imprimir entrega el PDF a la aplicación o servicio que tú eliges, mediante mecanismos de Android.

Esos proveedores pueden guardar o transmitir el documento, usar Internet, servicios en la nube o una red de impresión y aplicar sus propias políticas. Si eliges una imagen almacenada en la nube, su proveedor o el selector del sistema puede necesitar una conexión para obtenerla. Estas operaciones no equivalen a que OinkPrint suba automáticamente tus proyectos a un servidor del estudio.

5. Conectividad, terceros y transmisión de datos

La compilación release revisada no declara permisos de Internet o de estado de red y no incluye un servicio de sincronización, cuentas, SDK analíticos ni SDK publicitarios. El guardado local, la edición y la generación de PDF funcionan sin conexión.

En esta versión no se implementa una transmisión automática de fotos, proyectos, identificadores publicitarios o telemetría a OINKZILLA STUDIOS o a servidores de anuncios. Room y Gson se utilizan para persistencia y serialización local. Esto no cubre las aplicaciones externas que elijas para abrir, compartir, guardar o imprimir, ni los servicios o diagnósticos del propio sistema operativo.

6. Publicidad y consentimiento

En el release descrito, la publicidad está desactivada y los SDK AdMob y UMP están excluidos del archivo distribuible. No se solicitan anuncios, no se accede al identificador publicitario y no se realizan solicitudes de consentimiento publicitario mediante UMP.

La integración se conserva únicamente en el proyecto de desarrollo para una posible versión futura. Si se publica una versión con anuncios, se revisarán esta política, la declaración de Seguridad de los datos y los mecanismos de consentimiento aplicables antes de distribuirla. No se debe confundir esa futura modalidad o debug con el release actual.

7. Conservación y eliminación

  • Proyectos: permanecen localmente para que puedas retomarlos después de cerrar o reiniciar. Puedes eliminarlos desde Proyectos, con confirmación. No se eliminan proyectos automáticamente.
  • Imágenes compartidas por proyectos: una misma copia privada puede ser utilizada por varios proyectos. No se borra mientras otro proyecto la necesite.
  • Registro de eliminación: puede conservarse en la base privada una marca con el ID, nombre, fechas y metadatos básicos del proyecto eliminado para impedir que un guardado retrasado lo haga reaparecer. No contiene sus páginas ni sus imágenes. Borrar los datos de la aplicación elimina también esos registros.
  • Temporales: Configuración permite limpiar archivos temporales innecesarios con confirmación. Los recursos privados sin referencias se consideran para limpieza cuando tienen más de 24 horas. Los PDF temporales también pueden eliminarse al preparar nuevas exportaciones según su antigüedad.
  • Todos los datos internos: Borrar datos de OinkPrint en los ajustes de Android o desinstalar la app elimina sus proyectos y copias privadas. No es una forma de conservar el trabajo.
  • PDF y archivos externos: los documentos guardados o compartidos fuera de OinkPrint se eliminan por separado en su ubicación o aplicación de destino. Eliminar el proyecto no elimina esas copias.

8. Copias de seguridad y transferencias

OinkPrint no ofrece copia propia en la nube ni sincronización entre dispositivos. La compilación revisada declara allowBackup=false. Las opciones de respaldo o transferencia del sistema pueden depender de Android y del fabricante; revisa sus ajustes y documentación. No garantizamos que un proyecto se recupere después de desinstalar, borrar datos o cambiar de dispositivo. Un PDF externo es una salida visual y no sustituye al archivo editable completo.

9. Consultas y solicitudes

Puedes escribir a oinkzillasupport@gmail.com para consultas de privacidad y soporte. Si envías un correo, recibimos tu dirección y el contenido o adjuntos que decidas compartir para atender esa consulta. No envíes documentos sensibles que no sean necesarios para explicar el problema.

El estudio no tiene acceso remoto a tus proyectos locales y no puede eliminarlos a distancia ni restaurar una copia que no recibió. Para gestionar los datos guardados en el teléfono, utiliza los controles indicados anteriormente. No prometemos plazos o procedimientos automáticos de acceso, eliminación o recuperación que la app no implementa.

10. Esta web y cambios de política

Esta página se aloja en GitHub Pages. Al visitarla, tu navegador se conecta al proveedor de alojamiento, que puede tratar datos de conexión conforme a su propia política. La sección de OinkPrint no añade herramientas de analítica ni formularios de seguimiento. El tratamiento de la web se distingue del funcionamiento local de la app Android.

Actualizaremos la fecha y el contenido si cambia el tratamiento de datos o se activa publicidad en una versión futura. La política de StockOink es independiente y no se sustituye por esta página.
